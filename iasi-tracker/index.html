Desktop overlay (Windows)

An always-on-top version with hotkeys that work while you're in game. Clicks pass straight through it, so it never takes focus from Star Citizen.

  1. Install AutoHotkey v2 from autohotkey.com.
  2. Put the file in its own folder and double-click it.
  3. Run Star Citizen in Borderless.
  4. F9 run · F8 undo · F6 mission · F10 timer (hold to reset) · F7 move. Double-click the tray icon to edit missions and prices.
Download IASI_Overlay.ahk

To show it on stream, add a Window Capture of "IASI Overlay" in OBS, or use Display Capture.

Use it in OBS

Add a Browser source with this address. It shows the readout alone on chroma green, so add a Chroma Key filter. Use &bg=transparent instead if you'd rather skip the key.

The browser source keeps its own progress, separate from this tab. To log runs in it, right-click the source in OBS and choose Interact. For hotkeys that work while you're in game, use the AutoHotkey desktop overlay instead.
